# Learning

Playground for learning and experimenting with different languages.
A personal collection of programming exercises, experiments, and small projects in Go, Python, C++, Java, and Lua. 
The repository covers language fundamentals, algorithms, design patterns, backend development, command-line tools, games, scraping, and machine learning.

Projects are organized by language or topic and have their own dependencies and entry points. 
There is no single application or repository-wide build command; some projects are works in progress.

## Repository contents

| Directory | Contents |
| --- | --- |
| [`architecture/`](architecture/) | Microservices implementation with Spring Boot. |
| [`cpp/`](cpp/) | An HTTP server experiment using cpp-httplib and an Allegro graphics/multimedia experiment, with CMake build files. |
| [`design-patterns/`](design-patterns/) | Go examples of the adapter, factory, and strategy patterns, each in a separate module. |
| [`go/`](go/) | APIs, terminal applications, scrapers, algorithms, messaging experiments, and other Go exercises. |
| [`lua/`](lua/) | A basic interactive script demonstrating console output, input, and recursive factorial calculation. |
| [`python/`](python/) | Scripts and projects covering games, APIs, tokenization, language models, fine-tuning, and general programming exercises. |
